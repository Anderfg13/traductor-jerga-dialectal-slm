# docs/

Carpeta para los documentos que se generan a lo largo del proyecto y que
no son código: borradores de secciones del paper, evidencia de
despliegue, resultados de pruebas de carga, guiones de sustentación,
etc.

Según el calendario de 10 semanas, aquí van a vivir (entre otros):

- `fase2_arquitectura_borrador.md`, `fase2_prototipo_borrador.md`,
  `fase2_resultados_borrador.md` — borradores de secciones del paper
  para la entrega de Fase 2.
- `despliegue.md` — pasos seguidos para desplegar el servicio en la
  nube y la URL pública.
- `pruebas_carga.md` — metodología y resultados de las pruebas de
  carga/latencia del servicio.
- `guion_demo_fase2.md`, `guion_sustentacion_final.md` — guiones para
  las sustentaciones.
- `fase3_resultados_pi1_borrador.md`, `fase3_resultados_completos_borrador.md`,
  `fase3_limitaciones_borrador.md`, `fase3_costos_y_futuro_borrador.md` —
  borradores de las secciones de Fase 3 (PI1/PI2/PI3, limitaciones,
  costos y trabajo futuro).

Estos borradores se integran después al `.tex` final del paper; no son
el paper en sí.
